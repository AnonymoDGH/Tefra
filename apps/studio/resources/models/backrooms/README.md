# Props de Backrooms

Obra propia, generada por `tools/blender/make_backrooms_props.py` con la API de Python de Blender (bpy). Licencia CC0.

- `troffer.glb`: lámpara fluorescente empotrada de 60 × 122 cm, con difusor emisivo.
- `vent.glb`: rejilla de retorno de aire del techo.
- `outlet.glb`: enchufe de pared.
- `switch.glb`: interruptor de pared.
- `door_frame.glb`: marco de puerta para un hueco de 0,9 × 2,1 m.
- `chair.glb`: silla plegable.

Para regenerarlos: `pip install bpy` (Python 3.13) y después `python3 tools/blender/make_backrooms_props.py`.
